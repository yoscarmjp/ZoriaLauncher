# Zoria Launcher

Interfaz de launcher de Minecraft construida con React + Vite y preparada para Tauri 2.

## Inicio rápido

```bash
npm install
npm run dev
```

Para abrir como aplicación Tauri, instala Rust y ejecuta `npm run tauri dev`.

La UI ya incluye navegación, selector de versión, tarjetas de instancias, modal para crear modpacks y estado de lanzamiento simulado. La lógica de descarga, autenticación y ejecución de Minecraft queda lista para conectarse en `src-tauri` mediante comandos Tauri.
